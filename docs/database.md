# Database

Eight tables in schema `users`: `company`, `user`, `user_group`, `user_group_member`, `permission`, `scope`, `grant` and `audit_log`. No stored procedures. Integrators pick **one** pack:

- [`db/postgres`](../db/postgres) — PostgreSQL / Supabase (golden)
- [`db/mssql`](../db/mssql) — SQL Server / Azure SQL

Never apply both packs to one instance. TypeORM `synchronize: false`. After SQL changes, apply the pack then `pnpm db:scaffold`.

Database name: `open_user_db`. Snake_case. `users."user"` / `users.[user]` and `users."grant"` / `users.[grant]` are quoted (reserved words).

Ids are UUID v7 generated by the app. `permission` (never Asset) holds the capability; `grant` links a user or a group to a permission at an optional scope.

There is no upgrade script from the old 16-table layout. Rebuild a dev database from `99_drop.sql`, the schema and the seed.

Seed (both packs): company `Default`; root scope `Application`; user `admin` / `changeme` (argon2id) with a company-wide `oum.admin` grant.

```
DATABASE_KIND=postgres|mssql
DATABASE_URL=postgresql://…   or   mssql://…
```

Wrong kind vs the actual server is a startup error.
